# 🪙 Kobo Share: own am small small

A practice app: own practice "shares" of everyday Nigerian small businesses (fictional examples) using **₦5,000,000 free practice credits, not real money**. A game for learning how owning a piece of a business works. All businesses are fictional examples. Simulated daily practice scores (including bad days), fluctuating share values, weekly challenge, share card and leaderboard. All data lives in your browser's localStorage.

Live: https://0xzahra.github.io/kobo-share/

Static HTML/CSS/vanilla JS, no build step.

> Kobo Share is a practice app. No real money. Not an investment or offer, not SEC-registered. Early-list sign-ups are interest only and stored locally. Admin counts by source: `?admin=1`.
