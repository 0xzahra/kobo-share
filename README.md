# 🪙 Kobo Share — Own am small small

A practice app: own fractional "slots" of everyday Nigerian businesses (illustrative examples) using **₦500,000 free practice credits — not real money**. Simulated, seeded daily payouts (including bad days), fluctuating slot valuations, portfolio, payout history and leaderboard. All data lives in your browser's localStorage.

Live: https://0xzahra.github.io/kobo-share/

Static HTML/CSS/vanilla JS, no build step.

> Kobo Share is a practice app. No real money. Real-money investing will only launch with a licensed partner.
